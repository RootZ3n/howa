# Hermes Daily Driver V1

Howa owns isolated execution, frozen fixtures, transcript/tool capture, deterministic validation, raw verdicts, and application-write-once, digest-sealed receipts. Luak consumes those receipts through the standalone `howa.hermes-daily-driver.receipt.v2` schema; neither repository imports the other. Read-only file mode is defense in depth, not filesystem immutability: the canonical digest makes later tampering evident.

`howa daily-driver list` prints the frozen suite. Each attempt receives a fresh synthetic fixture while trusted Hermes state, usage, tool transcript, mutation snapshots, and validator output live in a separate host-owned capture root that candidate tools cannot mount. Hermes retains the one selected provider credential and provider network path; terminal/process calls run in a minimal bubblewrap view with no network, no host root, an empty environment, an explicit V1 executable allowlist plus read-only shared libraries, and only the minted fixture. The candidate report carries no identity or cost authority.

The committed V2 JSON Schema is executed before the stricter semantic invariants. V2 binds the launcher and executable bytes, exact redacted arguments, requested route/model/reasoning/temperature, accommodations, enforced turn/output-token limits, trusted served identity, and separate charged/API-equivalent/plan-credit/subscription-quota accounting. The effective configuration digest also covers those arguments, the launcher/executable digests, limits, and environment policy. The system-prompt digest covers the exact trial prompt plus the installed Hermes prompt-builder digest; the tool-registry digest covers the installed Hermes registry/model/terminal implementations, enabled toolsets, and the trial allowlist. The dated rate card is `howa.ddv1-rates.2026-08-22.1`. Unknown cost fails budget enforcement; it is never treated as zero.

Receipts are canonical sorted-key JSON, SHA-256 sealed, written once with `O_EXCL`, and made read-only. The schema rejects unknown keys, secrets, unsupported versions, broken evidence links, inconsistent acceptance, and identity mismatches. Artifact files are also write-once. Luak must preserve receipt bytes unchanged and store derived scoring separately.

The trusted Hermes launcher starts with `env -i`, a fresh capture home, and exactly one provider credential. Direct providers receive only their matching API-key environment variable. The Codex subscription route receives a two-token credential bundle which Howa validates and rewrites as a minimal, single-provider `auth.json` inside the trusted capture root; the bundle variable is not forwarded into Hermes. The terminal shim creates a separate empty mount and network namespace, mounts no host home or root, clears its environment, and exposes only the synthetic fixture, an explicit command allowlist, the Hermes-pinned Node executable, and read-only shared libraries. The runner validates the exact `/tmp/howa-ddv1-*` roots before launch.

The control campaign is intentionally not automatic. See `campaigns/hermes-daily-driver-v1/README.md` after the evaluator self-tests pass.
